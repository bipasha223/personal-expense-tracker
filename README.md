# Personal Expense Tracker

## Overview

This project is a Java application used to manage and track daily expenses. Users can store expense details, generate reports, identify the highest expense category, and save data using file handling.

## Features

* Add daily expenses
* Display all expenses
* Generate monthly expense report
* Identify highest expense category
* Save expense data into file
* Supports multiple entries

## Technologies Used

* Java
* ArrayList
* HashMap
* File Handling
* Classes and Objects

## File Included

* `ExpenseTracker.java`

## Output File

* `expenses.txt`

## Sample Output

```text
Total Expense = 2500.0
Highest Expense Category: Shopping = 2000.0
```

## How to Run

1. Compile the program:

```bash
javac ExpenseTracker.java
```

2. Run the program:

```bash
java ExpenseTracker
```
